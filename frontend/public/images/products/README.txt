Manual product images

Place JPG images in this folder using the product ID as the filename:
- mango.jpg
- lemon.jpg
- chilli.jpg
- garlic.jpg
- mixed.jpg
- green-chilli.jpg
- sweet-mango.jpg
- ginger.jpg

The storefront uses the database image URL when one exists; otherwise it automatically tries /images/products/<product-id>.jpg and falls back to the built-in placeholder if the file is missing.
